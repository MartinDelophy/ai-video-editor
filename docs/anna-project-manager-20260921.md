- Anna 新建改用应用内命名弹窗，绕过原生 `window.confirm` 依赖；当前工程确认保存后才清空时间线。切换先读取并验证目标、保存当前编辑，然后恢复。处理中出现新的编辑会中止替换，保留编辑器内容。
- 独立云端目录保存项目引用，沿用不可变媒体和快照、CAS 冲突检测及提交后才显示保存成功的约束。旧单工程只读迁移为第一项；旧版客户端写入旧键不会覆盖新目录。迁移后旧客户端的新编辑不会自动并入新版目录，升级时应关闭旧窗口。
- 每个项目保留最近一份恢复引用；恢复前保存当前内容，已有完整媒体快照仍可重用。目录最多 201 项（当前 + 200 个其他项目），超出时拒绝提交，不删除项目。更早的孤立文件不会自动识别为项目列表。
- 新建和恢复重置当前编辑器的撤销栈，避免撤销跨项目带回旧内容；13 种界面语言均有直接文案。
