Browser editing workspace

A free AI video editor with a real multi-track timeline

Timeline Studio is a free, open-source AI video editor that opens directly in a desktop browser. Import local media, arrange clips on a multi-track timeline, create voiceovers and captions, apply editable effects, and export without first uploading the project to an editing backend.

What can you edit?

The timeline supports a contiguous primary visual track plus timed overlays, captions, source audio, voiceovers, music and stickers. Clip operations include splitting, moving, trimming, duplication and deletion. Visual controls include transforms, masks, filters, animation, speed controls for video and editable color grading.

Where does AI fit?

AI results remain editable assets instead of one-click opaque outputs. Timeline Studio provides multilingual voiceover, automatic captions, browser-local AI music, smart framing, subject effects, video repair and talking-portrait workflows. Large models load only when their feature is requested.

What stays local?

Selected project media and core editing operations are processed in the browser. Model and runtime files can still be downloaded from configured, revision-pinned hosts, so “local-first” does not mean the application makes no network requests.

Browser and device requirements

A current desktop Chromium-based browser provides the broadest WebAssembly, WebGPU, WebCodecs and export support. Large AI workflows and high-resolution exports depend on available memory and GPU performance.
