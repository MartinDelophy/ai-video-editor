# Anna 窗口适配验收 · 2026-09-12

分支：`codex/anna-validation`。布局修改与本地尺寸矩阵于 9 月 11 日完成，最终构建及 Anna 生产草稿验证于 9 月 12 日完成。

## 问题与修复

Anna 当前窗口管理器优先恢复已存几何尺寸，没有按宿主可见区域限制窗口。本次生产窗口位于 `(252,77)`，尺寸为 `1440×900`，而宿主可见区域只有 `851×914`，右侧和底部被截断。编辑器原来的桌面预览最小高度也会在矮窗口中把时间轴推到可见区域之外。

- 新增 `annaWindowLayout.js`：SDK 连接后核对自身窗口 UUID，只读同源宿主中自身窗口的实际边界，通过官方 `window.resize` 收缩右侧或底部越界尺寸，预留 12px 边距。不放大用户已缩小的窗口、不改位置、不直接修改宿主 DOM。
- 监听宿主尺寸与自身窗口样式变化；450ms 防抖避开打开和拖动动画，串行执行 resize，相同失败边界不重复请求。断开时清理监听器；隐藏或无效尺寸跳过。
- Manifest 保留 `1440×900` 默认尺寸，将最小尺寸改为 `360×480`，列出 `window.resize`。没有新增 Agent 声明或其它业务权限。
- 矮桌面窗口按实际高度分配预览和时间轴，保留内部滚动；小 iframe 预留预览、播放控制和底部工具栏空间。修正中等宽度时间轴多出的 6px 右侧溢出，以及最窄视口的播放时间文字碰撞。普通桌面宽度档位与控件字号保持原有设计。
- 同步 11 份现有根 README 的本地化更新，每份保留最近五条。

## 代码检查与边界

目标文件 ESLint、typecheck、Anna 构建、普通构建、CLI 严格校验、diff 空白检查通过。构建保留既有大包、混合静态/动态导入和运行时依赖警告。仓库外的实际模块检查覆盖无效或零尺寸、保留小窗口、隐藏窗口、身份不匹配、失败去重、并发 resize、请求期间边界变化和停止清理。

此适配只能调整宽高。若窗口已完全移到屏幕外，或当前位置剩余空间不足最小 `360×480`，仍需用户移动窗口或 Anna 提供宿主重定位支持；未来跨源宿主也需要官方提供可见区域接口。没有通过更宽权限或修改宿主页面绕过这一边界。
