# Automatic speech ducking

The Audio property tab exposes one switch and a strength selector for ordinary audio, music and video-source audio, including individual linked source pieces. New clips default to off. Turning it on analyzes other audible speech sources locally using the existing owned, pinned and checksum-verified Silero ONNX/WASM model. It does not use Anna ASR or consume cloud transcription credit. Muted/hidden sources, the target itself, and the dedicated Music track are excluded from detection. Two overlapping enabled targets may each duck in response to the other's original speech; detection is not fed back from the ducked mix.

Gentle, Natural and Strong reduce gain by 6, 12 and 18 dB, respectively. The shared envelope anticipates speech by 80 ms and restores over 450, 650 or 900 ms. Close speech intervals merge to prevent pumping. Detection happens in source time, then maps through source trims, playback rate and speed curves to timeline time. The sparse envelope multiplies the existing volume/fade gain. Preview and both video-export pipelines use that same envelope; clip audio downloads preserve the original timeline offset. Closing the switch removes only the derived ducking gain and retains existing source media, volume and fades.

Source edits, timing, speed, visibility and base gain changes invalidate the current scene. Outstanding inference aborts, and bounded cached source probabilities are reused when possible. Long sources use the existing bounded-window decoder; inference does not keep a fully decoded movie in memory. Export refuses enabled clips until their analysis is ready, rather than silently exporting unchanged levels. An error is localized and may be retried by toggling off and on. Reversed speech sources currently produce a visible analysis failure. Music mixed into source video can confuse speech detection; review real dialogue and music-heavy scenes before relying on the result.

Only clip settings persist: `autoDuck: { enabled, strength }`, `sourceAudioAutoDuck` on linked visuals or the unlinked source root. Derived model results and envelopes are transient and recomputed after restore. Normal clip identity, undo/redo, source-to-audio moves and archive persistence retain settings. `audio.configure` exposes `settings.autoDuck` for ordinary audio clips through the existing inspect/preview/apply contract; source and music controls remain UI-based. No editable timeline envelope handles are shipped by this change.

The inspector shows a spinner, localized model-loading/audio-decoding/speech-detection phase and a full-width progress rail. The numeric percentage remains visible from 0%; unknown download progress keeps an indeterminate rail rather than inventing advancement. Actual download bytes, decoded packet coverage and model inference drive progress. Ready clips with no other detected speech explicitly report that no ducking is needed. Source, ordinary audio and music timeline clips subscribe to the same derived envelope used in playback/export and draw its attenuation/recovery shape over the waveform. The overlay is read-only; the existing gain drag and keyboard controls continue editing base gain.

## Voice enhancement in the Audio inspector

Source and ordinary audio clips expose a separate, default-off Voice enhancement switch using the same compact strength/status layout. Enabling automatically processes the clip with the existing pinned DeepFilter WASM engine, a restrained three-band EQ, linked-channel compression, makeup gain and a -1 dB limiter. Gentle/Natural/Strong choose 40/65/85% denoising and bounded DSP presets. This is speech cleanup, not speaker separation or ASR. Strength changes process the retained original again rather than stacking enhancement.

Successful processing uses the shared detailed-processing commit helper. Timing, speed, gain, fades and clip associations remain unchanged; source segments follow the existing source-to-audio-lane route with an original backup. Turning the switch off restores the retained original. The Audio inspector provides original/enhanced audition buttons scoped to the source trim. Cancelling, switching clips, changing source trims or locking the track aborts pending work; results from a superseded source never apply. Failure retains the last committed audio and offers Retry. All feature copy is supplied directly in 13 interface languages. Saved settings use audioProcessing.speechEnhancement with gentle/natural/strong, alongside the existing processing settings and original-media archive fields.

Ducking keeps one warm Silero worker per mounted editor and resets its recurrent state between source clips. Repeated model downloads/session creation are avoided; cancellation during inference discards that worker, and unmount always disposes it. Probability caching keys only the source blob and source-time range, so strength changes, moves and speed changes that retain the same source range reuse detection. Decode downmixing caches channel views per packet rather than resolving them per sample.
