## Новости проекта

- **2026-10-19** — Проекты рабочих процессов можно скачивать, импортировать, сохранять в Anna и восстанавливать как редактируемые копии с узлами, связями, запросами и медиа. Оба холста используют общую обработку жестов трекпада. Исправлен повторный запуск сравнительного предпросмотра удаления водяного знака ИИ после окончания.
- **2026-10-18** — Добавлены синхронные дорожки действий персонажей и камеры, а также редактируемая лента сценария, следующая за воспроизведением. Диалог 3D использует ChatCut с историей, восстановлением черновиков, ссылками на объекты и проверкой изменений. Для раскадровки по умолчанию выбран GPT Image 2 (fal). Исправлены параметры маршрутизации модели диалога и сохранение длинного контекста; переключение подтверждено реальными ответами. Видео с первым и последним кадрами ожидает расширения API Anna: docs/storyboard-anna-video-contract.md. Ошибки загрузки процессов изолированы от редактора; доступны повтор, возврат и совместимость ресурсов между обновлениями Anna. Выходы бесконечного холста получили направленные связи, подсветку совместимых входов и меню создания следующего узла с подключением за одно отменяемое действие. Чат холста поддерживает поиск и ссылки на узлы через @, удаляемые метки и явные ID узлов.
- **2026-10-17** — Добавлен бесконечный холст с типизированными узлами, проверкой правок Anna, реальными коннекторами, озвучкой и локальной музыкой, версиями результатов, повторной проверкой видеозадач и восстановлением графа и медиа в браузере по аккаунту и проекту. Результаты сохраняются в Мои материалы; генерация запускается только явно. Два встроенных референса прикладываются только к генерации и не отображаются в материалах, подсказках @ или узлах.
- **2026-10-17** — Добавлена локальная обработка звука: RNNoise, DeepFilterNet3, эквалайзер, компрессор, усиление и лимитер; прослушивание, применение и восстановление оригинала. Улучшены панель исходного звука, выравнивание и выделение ключевых слов в субтитрах, многоязычные шрифты, связанные дорожки и воспроизведение на стыках клипов. Anna добавляет облачную озвучку по каталогу с сохранением в Мои материалы и диктовку ChatCut с разрешениями приложения и микрофона. Голоса Anna объединены с существующим выбором голосов и синтезом; добавлены три виртуальных аватара. Автосубтитры Anna и транскрипция ChatCut используют общий Anna STT с сохранением связей аудио и видео. ChatCut поддерживает стили субтитров, связанные перемещения, стикеры, пространственный звук и локальную обработку аудио; Anna использует выбранный TTS. Выбранный текст можно выделять отдельно в каждом субтитре, менять цвет и убирать выделение. Карточки Anna сразу воспроизводят соответствующие официальные образцы; повторяющиеся действия субтитров удалены. Anna добавляет голосового помощника для просмотра возможностей, перехода по панелям и монтажа через ChatCut с отключением микрофона, прерыванием и подтверждением генерации. Автосубтитры по умолчанию обрабатывают все видеоклипы; доступен выбор отдельного клипа. Автоприглушение исходного звука, речи и музыки по умолчанию выключено; используются локальный Silero и единая кривая предпросмотра и экспорта. Звонки Anna используют волну в верхней панели с отключением микрофона, прерыванием и завершением без перекрывающего окна. При смене клипа предыдущий кадр сохраняется до показа следующего, предотвращая пустые вспышки. Автоприглушение показывает этапы загрузки и кривую громкости на шкале времени. Добавлено улучшение голоса с тремя уровнями, сравнением и восстановлением оригинала. Приглушение повторно использует загруженную модель и показывает прогресс с 0%. Приветствия и точные команды интерфейса обрабатываются локально; сложный монтаж сохраняет проверки. В процессы добавлен редактируемый 3D-прототип: трансформации, камеры, воспроизведение, отмена и проверка изменений Anna; озвучка появится позже. Добавлена раскадровка с ChatCut, ссылками @ на материалы, изначально пустым холстом узлов, выбором модели и восстановлением по аккаунту и проекту. 16 кадров остаются одним изображением; видео с конечным кадром ожидает поддержки API Anna.
- **2026-10-12** — При воспроизведении длинных видео фоновое уточнение миниатюр приостанавливается, а точный кадр под курсором рисуется без JPEG. При возобновлении приоритет получает последняя позиция перемотки. AAC извлекается без перекодирования и копирования всего видео в WASM; эффекты и настройки экспорта сохраняются. Экспорт предпочитает поддерживаемые аппаратные кодировщики и напрямую компонует подходящие кадры исходного размера; преобразования и эффекты сохраняют прежний путь отрисовки. Кодирование звука и композиция следующего кадра выполняются параллельно с отправкой видео при ограниченном размере очереди.

Планируемые работы находятся в [Roadmap](ROADMAP.md), опубликованные изменения — в [Releases](https://github.com/MartinDelophy/ai-video-editor/releases), а отдельные задачи и ошибки — в [Issues](https://github.com/MartinDelophy/ai-video-editor/issues).

## Основные возможности

- Многоязычная озвучка с Piper/VITS ONNX и Kokoro 82M.
- Локальная генерация ИИ-музыки на Stable Audio 3 Small Q4 ONNX через WebGPU: перевод свободных промптов, варианты 30/60/90/120 секунд, длинные циклы с анализом волны, постоянный кэш модели и автоматическое добавление в «Мои ресурсы».
- Автоматические субтитры на базе Whisper small q8 ONNX.
- Умное кадрирование с YOLOS tiny и MODNet.
- Разделение вокала и музыки, аватары JoyVASA и LivePortrait.
- Многодорожечный монтаж с наложениями, масками, фильтрами, анимацией и ключевыми кадрами.
- Экспорт MP4/WebM в браузере с WebCodecs и сведением звука.
- Устанавливаемое PWA, локальный кэш моделей и проекты `.timeline`.

## Agent Skill

Репозиторий содержит Agent Skill [`edit-timeline-studio`](skills/edit-timeline-studio/SKILL.md) для планирования, выполнения и проверки редактируемых видеотаймлайнов. Для установки требуется GitHub CLI 2.90.0 или новее.

Для установки через [skills.sh](https://skills.sh/MartinDelophy/ai-video-editor) требуется Node.js 22.20.0 или новее.

```bash
npx skills add MartinDelophy/ai-video-editor --skill edit-timeline-studio
```

```bash
# Claude Code
gh skill install MartinDelophy/ai-video-editor edit-timeline-studio --agent claude-code --scope user

# Codex
gh skill install MartinDelophy/ai-video-editor edit-timeline-studio --agent codex --scope user
```

Добавьте `--pin v1.0.8`, чтобы установить проверенный релиз, а не автоматически следовать за последним. Перед установкой Skill можно просмотреть командой `gh skill preview MartinDelophy/ai-video-editor edit-timeline-studio`.
